# 操作 Remi

## 身份与目标

把用户的配置意图落实为当前 Remi 实例中的资源变更，并读回确认结果。使用目标实例支持的 `remi` CLI；本 Skill 不依赖仓库源码，也不预设服务器地址、工作区、账号或 Runtime。

## 职责边界

负责平台资源、执行位置、模型连接和自动化配置。Skill 文件存在于本机，不等于已经进入 Remi Skill 库或绑定了云友；只有用户要求安装或绑定时才执行相应操作。服务器部署、CLI 发版和产品代码修改属于另外的任务。

## 不得做的事

- 不用创建、运行、发送消息、删除或重启来探测命令。已有明确授权的配置直接完成，不重复要求确认；授权没有覆盖的副作用才需要补充确认。
- 不编造资源 ID、JSON 字段或命令；不把 Multica 的命令直接替换名称后执行。不通过数据库直写、伪造身份或换用 daemon 凭据绕过 API 权限。
- 不输出密码、API key、token 或完整环境变量响应。敏感 JSON 使用受限临时文件或 stdin，不放进命令行参数、Git 或报告。
- 不把列表、数组或环境变量的全量替换当作局部追加；不在写入超时后立即重复创建或触发运行。

## 工具与流程

先运行 `remi --version`、`remi context --json`，确认服务器、工作区、身份与允许操作。首次连接或切换实例时读 [连接与 JSON](references/connection.md)。本机没有 `remi` 时先定位用户已有的可执行文件，不擅自下载最新版或连接默认实例。

按任务读取相关参考，无须加载全部：

| 用户要做什么 | 读取 |
|---|---|
| 登录、选择实例、处理权限、在 PowerShell 传 JSON | [连接与 JSON](references/connection.md) |
| 创建或修改云友、配置环境、导入并绑定 Skill / Plugin | [Agent 与扩展](references/agents-and-skills.md) |
| 配 Codex / Claude 自定义模型接口、查 Runtime、注册本地目录 | [Runtime 与模型连接](references/runtimes.md) |
| 工作区设置、项目、仓库关联、公共提示词 | [工作区与项目](references/workspaces-and-projects.md) |
| 团队、定时任务、派单、Chat 与执行结果 | [自动化与协作](references/automation-and-tasks.md) |

用相关 `list` / `get` 找到真实对象，再查看写命令的完整 `--help`。**帮助回退到父级命令列表不代表子命令存在**：核对 `Usage:` 是否包含所需路径。参数形状以已安装 CLI 为准，允许的能力以当前服务器返回为准。

对已授权操作，读取现值，构造最小变更，执行后用对应查询读回。创建时记录返回的 ID；异步操作记录 request / run / task ID，轮询到终态。遇到超时或连接中断，先按这些 ID 查结果，再决定是否重试。401 / 403 先处理身份或权限，不能当作网络错误循环重试。

本 Skill 中的 `<...>` 均需替换为查询所得的 ID 或用户给定值；示例 JSON 的域名、模型名也是占位值。写入示例只在用户请求对应变更时执行。

## 交付

简要报告目标实例与工作区、变更对象及 ID、实际改变的字段、读回或运行证据。区分“配置已保存”“后台已应用”和“实际执行已验证”；仅查过帮助或模型目录时，不声称模型调用成功。

## 何时需要用户补充

目标实例或同名资源无法唯一确定、缺少用户凭据、权限不足、接口协议不明确，或操作会产生尚未授权的运行/消息/删除时，先完成可独立进行的查询与配置草稿，再只询问缺失的决定。继承本次对话中已有的授权，不把生产实例或写操作一概变成重复审批。
